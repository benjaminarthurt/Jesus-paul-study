# Sources and bibliographic records

This directory will contain standardized source records for biblical editions, critical commentaries, historical research, and scholarship. Include author, full title, edition/year, publisher or journal, page/section, URL/DOI/ISBN when available, and a record of what was actually checked.

Suggested books **to verify and read before citing** include E. P. Sanders, *Paul and Palestinian Judaism*; Paula Fredriksen, *Paul: The Pagans' Apostle*; Amy-Jill Levine, *Short Stories by Jesus*; and scholarly introductions to the New Testament.

These suggestions are **not** citations in support of the present draft comparison pages.

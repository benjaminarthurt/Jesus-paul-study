# Jesus and Paul: A Textual and Historical Study

A research-first project examining the teachings attributed to Jesus in the canonical Gospels, Paul's undisputed letters, disputed Pauline writings, and their interpretation in contemporary Christianity.

**Status:** foundation in development. The repository is private; findings are provisional until evidence and citations have been reviewed.

The project distinguishes direct textual claims, historical reconstruction, interpretation, and modern ethical application. Apparent disagreements are tested against the strongest available readings in context.

See `docs/` and `research/` as the project grows.

# Research and implementation agent instructions

This project is a historical-textual comparison, not a polemic. Do not manufacture scholarly consensus, verse quotations, Greek glosses, or modern positions.

1. Never promote `draft` research to `source-checked` without inspecting supporting primary passages and reputable scholarly sources.
2. Do not equate the six disputed Pauline letters with Paul's seven generally undisputed letters without stating the attribution debate. Do not attribute Hebrews to Paul.
3. Separate textual observation, authorial/historical inference, theological reading, and modern ethical application.
4. Cite alternative interpretations and relevant manuscript uncertainties. Distinguish agreement, different emphasis, extension, apparent tension, direct contradiction, and insufficient evidence.
5. Every passage reference in research frontmatter must resolve to `research/index/passages.json`. Every structured relationship uses a stable ID.
6. Do not copy substantial text from copyrighted Bible translations or commentaries. Use references and original paraphrases until publication rights are verified.
7. Do not remove or silently revise scholarly disagreements. Add correction notes and preserve the git history.
8. Run `npm run check` and `npm run build` when the environment supports dependency installation. Describe tests not run.
